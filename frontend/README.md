MIZARDO FRONTEND (animated) — Quick Start

1. Install dependencies:
   npm install

2. Run dev server:
   npm run dev

Notes:
- VITE_API_URL environment variable (in frontend/.env) controls backend URL.
- Uses Tailwind CSS v3.4.10 to avoid registry issues.
- Contains animated components (Framer Motion) and placeholder fallback data when backend is unavailable.
